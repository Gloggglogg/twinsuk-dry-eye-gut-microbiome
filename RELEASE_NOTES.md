# Version 1.0.0

This release preserves the analysis source accompanying manuscript version 49. It adds a portable runner, synthetic input generator, aggregate reference results and source fingerprints. Input and output paths are configurable, and historical standalone Python launchers are disabled.

The release includes the study's richness and Shannon-diversity regressions, symptom-score analyses, sensitivity analyses, twin models and R genus-method source. Separate commands identify optional community permutations and twin bootstrap resampling. The supplied synthetic example exercises the portable workflow. Saved study aggregates support comparison after approved-data reproduction.

The custom community procedures retain their original implementation. Assessment of their statistical assumptions remains pending. The twin covariance analysis remains exploratory, with imprecise component estimates. This release establishes source preservation and the computational checks recorded in `verification.json`; it does not supply an independent reanalysis of protected participant data.
